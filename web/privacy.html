מדיניות פרטיות (Privacy Policy)

עודכן לאחרונה: ספטמבר 2026

ברוכים הבאים לפלטפורמת שחמט מקוון בנטפרי ("האפליקציה"). אנו מכבדים את פרטיות המשתמשים ומחויבים להגן עליה בכל עת. מסמך זה מפרט כיצד האפליקציה מתקשרת עם חשבון Google של המשתמש, אילו הרשאות נדרשות, וכיצד המידע מנוהל ומאובטח.

1. מהות האפליקציה והשימוש ב-Google API

האפליקציה הינה תוכנת שולחן עבודה עצמאית (Desktop Application) המאפשרת למשתמשי אינטרנט מסונן (בפרט נטפרי) לשחק שחמט מקוון מול חברים, תוך שימוש בלעדי ב-Google Sheets API כשרת סנכרון מהלכים וצ'אט, ללא צורך בשרת פרטי או WebSockets.

2. הרשאות גישה (Google OAuth Scopes)

האפליקציה מבקשת הרשאה אחת בלבד:

  • https://www.googleapis.com/auth/spreadsheets – קריאה וכתיבה של קובצי גיליונות אלקטרוניים (Google Sheets).

מדוע נדרשת הרשאה זו?
הרשאה זו נדרשת אך ורק כדי לכתוב ולקרוא את מהלכי השחמט, מצב החדר (Metadata) והודעות הצ'אט בגיליון שהוגדר על ידי המשתמש (או שנוצר על ידיו בלחיצת כפתור באפליקציה).

3. איסוף, שמירה ושיתוף נתונים

הצהרת אי-איסוף מידע אישי:
האפליקציה אינה אוספת, אינה שומרת ואינה מעבירה שום מידע אישי, פרטי זיהוי, כתובות דוא"ל, אנשי קשר או קבצים אישיים מ-Google Drive לשום שרת חיצוני, צד שלישי או מסד נתונים.
  • אחסון מקומי: אסימון ההתחברות (OAuth Token) נשמר באופן מאובטח ומקומי בלבד במחשב המשתמש בקובץ token.json, לצורך שמירת ההתחברות בין הפעלות של התוכנה.
  • תקשורת ישירה: כל התקשורת מתבצעת ישירות בין המחשב של המשתמש לבין השרתים המאובטחים של Google דרך HTTPS (תוך שימוש בתעודת האבטחה הרשמית של נטפרי).
  • שיתוף נתונים: המהלכים והודעות הצ'אט נרשמים אך ורק בגיליון השחמט הספציפי ששותף בין שני השחקנים.

4. תאימות למדיניות נתוני המשתמש של Google API

השימוש של האפליקציה במידע המתקבל מממשקי ה-API של Google עומד במלואו ב-Google API Services User Data Policy, כולל דרישות השימוש המוגבל (Limited Use requirements).

5. מחיקת נתונים וביטול גישה

המשתמש יכול לבטל את גישת האפליקציה לחשבונו בכל עת באמצעות:

  • כניסה לניהול חשבון Google: ניהול אפליקציות עם גישה לחשבון והסרת ההרשאה לתוכנה.
  • מחיקת הקובץ המקומי token.json מתיקיית התוכנה במחשב.

6. יצירת קשר

לשאלות, בירורים או דיווח בנושאי פרטיות ואבטחה, ניתן לפנות למפתחי הפרויקט דרך מאגר ה-GitHub של הפרויקט.
