# 🎮 פלטפורמת משחקי לוח מקוונת בנטפרי (NetFree Boardgames)

פלטפורמת משחקי לוח מקוונת רב-משחקית לשחקן מול שחקן (PvP) הפועלת ישירות מול **Google Sheets API**.
הפלטפורמה מותאמת ב-**100% לסינון נטפרי**, ללא תלות בשרתים חיצוניים, ללא WebSockets, וללא צורך בפתיחת פורטים!

---

## 🏆 המשחקים הנתמכים

1. **♟️ שחמט מקוון (Chess)**
   - מנוע חוקים בינלאומי מלא לפי תקן FIDE (הצרחה, הכאה דרך הילוכו, הכתרת כלי, פט, שח-מט).
   - שעוני זמן דיגיטליים (בליץ, 5 דק', 10 דק', 15 דק' + 5 שניות).
   - צ'אט חי בזמן אמת, הצעת תיקו, כניעה והחזרת מסע (Takeback).
   - ייצוא מהלכי משחק בפורמט תקני (PGN).

2. **⚪ דמקה ישראלית / בינלאומית (Checkers 8x8)**
   - לוח עץ אינטראקטיבי של 64 משבצות ו-12 דיסקיות לכל צד.
   - **חובת אכילה קפדנית (Mandatory Captures)**.
   - **שרשרת אכילות רציפה וקפיצות מרובות** בתור יחיד.
   - **מלכה (דמקה) מעופפת 👑** הנעה וקופצת לאורך כל האלכסון.
   - שעונים דיגיטליים וצ'אט חי.

3. **🎲 שש-בש מסורתי (Backgammon)**
   - לוח 24 משולשים מדורגים עם סידור כלים קלאסי (15 כלים לכל צד).
   - **מנגנון הטלת קוביות תלת-ממדיות** (כולל טיפול מלא בדאבל – 4 מהלכים).
   - חובת כניסה מהמשקוף (Bar), אכילת כלים בודדים (Blot), והוצאת כלים (Bearing Off).
   - זיהוי סוגי ניצחון וניקוד: ניצחון רגיל (נקודה 1), מארס (Gammon - 2 נק'), ומארס טורקי (Backgammon - 3 נק').

## 🚀 תכונות מרכזיות

- **Gaming Dark HUD Theme**: ממשק משחקי מודרני, יוקרתי ואינטואיטיבי.
- **מרכז משחקים מאוחד (Platform Launcher Hub)**: בחירה נוחה של כל משחק ממסך בית אחד.
- **קוד הזמנה חכם מורחב (Smart Invite Code)**:
  `NETFREE#<SHEET_ID>#<GAME_TYPE>#<ROOM_ID>` – מזהה אוטומטית את סוג המשחק ומכניס את השחקן מיד לחדר.
- **לובי מרכזי רב-משחקי (Realtime Lobby)**: צפייה בכל החדרים הפתוחים עם אפשרות סינון לפי משחק.
- **הגנת נטפרי מובנית**: תעודת השורש של נטפרי (NetFree Root CA) משולבת אוטומטית בכל החיבורים למניעת שגיאות SSL.

## 💻 דרישות והרצה

### הרצה מקוד מקור (Python):
```bash
pip install -r requirements.txt
python main.py
```

### דגלי הרצה ישירים:
- `python main.py` – פתיחת מרכז המשחקים הראשי
- `python main.py --chess` – שחמט ישיר
- `python main.py --checkers` – דמקה ישירה
- `python main.py --backgammon` – שש-בש ישיר
- `python main.py --test` – כלי בדיקות ואבחון נטפרי
